# 要件定義: GitHub Actions CI 実装

## 概要

プルリクエストのたびに自動でビルド・テストを実行する CI ワークフローを GitHub Actions で構築する。

---

## 要件一覧

### トリガー

- すべての `pull_request` イベントで実行する
- パスフィルターは設けない（すべての変更を対象とする）

### ランナー

- `ubuntu-24.04` を使用する（バージョンを固定し、再現性を担保する）

### タイムアウト

- ジョブ全体のタイムアウトを **5分** に設定する

### Concurrency（同時実行制御）

- `github.workflow` と `github.ref` の組み合わせをキーとする
- 同一ブランチで新しいワークフローが起動したとき、古い実行を自動キャンセルする

### Java バージョン

- **Java 21** を使用する

### ビルドコマンド

```bash
./mvnw clean verify
```

- テスト（単体・結合）およびカバレッジレポート生成を含む

### 静的解析

- 今回のスコープ外とする

### セキュリティ

- `permissions: contents: read` を明示設定し、`GITHUB_TOKEN` の権限を最小化する

### Maven キャッシュ

- `actions/setup-java@v4` の `cache: 'maven'` オプションを利用してキャッシュを有効化する
- 依存関係の再ダウンロードを防ぎ、ビルド時間を短縮する
